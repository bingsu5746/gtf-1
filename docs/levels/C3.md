# C3 레벨 기획서 (초안)

**[검토]** 표시는 연우님이 정해 줘야 하는 부분, **[확인 필요]**는 연우님 PC의 원작 덤프나 게임 테스트로 확인할 부분이에요.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 이름 | **[검토]** 제안: "Last Record" |
| 이야기 | ECHO의 마지막 기록 발견. 그들도 리액터 앞까지 갔다가 연락이 끊겼다. |
| 주 목표 | 중앙 발전기 클러스터 (유형 9) |
| 보조 / 추가 목표 | 없음 |
| 콤플렉스 | 연구 시설 |
| 처음 나오는 적 | 잠든 마더(36), 베이비(38), P-마더(37), 메가 마더(55), Shooter_Big_Infection(34) |
| 플레이 느낌 | D1 직전의 큰 고비. 잠든 마더를 피해 가고, 마지막에 메가 마더와 맞서요. |

## 2. 목표 설정

- 한 곳에 모인 발전기에 셀을 모두 꽂아요. 셀은 다른 구역에 흩어져 있어요.
- 발전기 수 / 셀 수: **4개**를 제안해요. **[검토]**
- 셀을 꽂을 때마다 안개가 단계별로 짙어지게 해요(중앙 발전기 목표의 단계별 안개 설정).
- 원작 R2D1 목표를 복사해서 시작해요. **[확인 필요]** R2D1 목표 블록 번호.
- **메가 마더:** 마지막 셀을 꽂으면 메가 마더가 나와요. **[확인 필요]** 원작 데이터에 메가 마더가 들어간 웨이브 개체군이나 적 그룹이 있는지 확인하고, 없으면 새로 만들어요.

## 3. 구역 구성

| 구역 | 역할 | 들어가는 문 | 적 | 이야기 장치 |
| --- | --- | --- | --- | --- |
| 0 | 착륙 지점 | (엘리베이터) | 없음 | Warden 브리핑 |
| 1 | 셀 구역 1 | Class III 알람(13) | 잠든 적 Medium | 셀 2개 |
| 2 | 마더의 둥지 | Class II 알람(12) | 잠든 마더 1 (은신 전용, Pure Sneak) | 셀 1개, ECHO 시체 |
| 3 | 셀 구역 2 | Class IV 알람(3) | 감염 빅 슈터 1, 잠든 적 Hard | 셀 1개 |
| 4 | 중앙 발전기 (넓은 방) | Class V 알람(32) | 셀을 꽂을 때마다 웨이브 | 발전기 4개, ECHO 마지막 기록 |
| 5 | 리액터로 가는 문 | 열리지 않음 | | D1로 이어지는 길만 보여 줘요 |

- 마더의 둥지: 마더를 깨우면 베이비가 몰려와요. 깨우지 않고 셀만 가져가는 게 정답이에요.
- P-마더: 셀을 꽂는 웨이브 중간(3번째 셀)에 넣는 걸 제안해요. **[검토]**
- 중앙 발전기 방은 넓어야 해요. 허브 방이 후보예요. **[확인 필요]**

## 4. 난이도와 자원

- 자원 배율: 0.6
- 시작 상태: 100%
- 메가 마더(HP 5,000)는 탄약을 아주 많이 써요. 중앙 발전기 방에 탄약 보급을 넉넉히 두는 걸 검토해요.

## 5. 분위기

- 안개: 셀을 꽂을 때마다 짙어져요. 마지막 단계는 감염 안개(INFECTION) 후보. **[검토]**
- 조명: 빨간 단색 조명을 중앙 발전기 방에 처음 써요. D1, E1로 이어지는 "위험" 색이에요.

## 6. 이야기 문구 (영어, 초안)

**Warden 브리핑**

> Activate the central generator cluster. Reactor access depends on it.

**레벨 설명**

> ECHO's trail ends near the reactor. Whatever they found, they found it here.

**ECHO 마지막 기록 (구역 4) — ECHO_LOG_09**

> ECHO-1: Last two of us. Generators are all online. The reactor door opened by itself.
> ECHO-1: Warden says start the reactor and the signal stops.
> ECHO-1: I don't believe it anymore. But there's no way back.
> ECHO-1: If anyone reads this. Don't start it.

**메가 마더가 나올 때 Warden 메시지**

> Biological interference detected. Eliminate. Proceed.

## 7. 데이터 작업 목록

1. 레이아웃 복사 → C3용 새 번호.
2. R2D1 목표 복사 → 발전기 수, 셀 수, 단계별 안개 수정.
3. 구역 2에 잠든 마더(은신 전용 배치).
4. 셀을 꽂을 때 웨이브, 마지막에 메가 마더.
5. RundownDataBlock의 TierC에 C3 추가.

## 8. 테스트 체크리스트

- [ ] 셀을 꽂을 때마다 안개가 바뀐다.
- [ ] 잠든 마더를 깨우지 않고 지나갈 수 있다.
- [ ] 메가 마더가 마지막 셀 뒤에 나온다.
- [ ] 메가 마더를 4인이 잡을 수 있는 탄약이 있다.
- [ ] ECHO 마지막 기록이 제대로 나온다.
