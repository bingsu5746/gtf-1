# B1 레벨 기획서 (초안)

**[검토]** 표시는 연우님이 정해 줘야 하는 부분, **[확인 필요]**는 연우님 PC의 원작 덤프나 게임 테스트로 확인할 부분이에요.
적 ID, 알람 ID 같은 숫자는 데이터 레퍼런스 보고서(게임 버전 34873 덤프 기준)에서 가져왔어요.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 이름 | **[검토]** 제안: "Turned" (슬리퍼들이 신호 쪽으로 몸을 돌린다는 뜻) |
| 이야기 | 신호에 가까워질수록 슬리퍼가 이상해진다. ECHO 팀원들의 ID 카드가 흩어져 있다. |
| 주 목표 | ID 카드 모으기 (작은 물품 모으기, 유형 3) |
| 보조 / 추가 목표 | 없음 |
| 콤플렉스 | 채굴 시설 |
| 처음 나오는 적 | 쉐도우(21), 쉐도우 스카우트(40), 빅 쉐도우(35) |
| 플레이 느낌 | 은신 중심. 안 보이는 적 때문에 조심스럽게 움직여야 해요. |

## 2. 목표 설정

- 모을 물품: 인원 ID 카드. 원작 R1B1이 ID 카드 12개를 모으는 레벨이라, 그 목표를 복사해서 시작해요. 덤프 확인(2026-10-25): R1B1 목표는 **167** "Rundown001_B1_Gather_Personnel_IDs_12", 레이아웃은 3988653479 "Rundown001_B1"이에요.
- 개수: ECHO 팀원 4명분이라는 설정으로 **4개**를 제안해요. 원작보다 적은 대신, 카드를 구역마다 하나씩 흩어 놓아서 맵을 다 돌게 해요. **[검토]**
- 다 모으면 엘리베이터로 돌아가요.

## 3. 구역 구성

| 구역 | 역할 | 들어가는 문 | 적 | 이야기 장치 |
| --- | --- | --- | --- | --- |
| 0 | 착륙 지점 | (엘리베이터) | 없음 | Warden 브리핑 |
| 1 | 첫 탐색 | 스캔만 | 잠든 스트라이커 | ID 카드 1, ECHO 시체 |
| 2 | 어두운 작업장 | Class I 알람(7) | 잠든 쉐도우 처음 등장 | ID 카드 2, 터미널 로그 1 |
| 3 | 갈림길 | Class II 알람(12) | 쉐도우 스카우트 1 | ID 카드 3 |
| 4 | 가장 깊은 곳 | Class III 알람(13) | 빅 쉐도우 1, 잠든 적 Medium | ID 카드 4, 터미널 로그 2 |

- 쉐도우는 투명해서 어두운 곳에서 강해요. 구역 2부터 조명을 어둡게 해서 처음 만나는 순간을 무섭게 만들어요.
- 스카우트 웨이브(ScoutWaveSettings, ScoutWavePopulation)는 쉐도우 위주로 바꾸는 걸 검토해요. 원작 웨이브 개체군 Shadows(7)가 후보예요.

## 4. 난이도와 자원

- 자원 배율: 0.7
- 시작 상태: 100%

## 5. 분위기

- 안개: A1보다 조금 진하게.
- 조명: 구역 2부터 DarkGrey_1 또는 DarkBlue_1 계열. 덤프 확인: DarkGrey_1은 **77**, DarkBlue_1은 **61**이에요. 비슷한 것으로 63 "DarkBlueToPurple_1", 76 "DarkGreyToOrange"도 있어요.

## 6. 이야기 문구 (영어, 초안)

**Warden 브리핑**

> ECHO team identification recovered in this sector. Retrieve all ID cards. Personnel status irrelevant.

**레벨 설명**

> ECHO's last known route leads here. Their ID cards are still transmitting. Their vitals are not.

**터미널 로그 1 (구역 2) — ECHO_LOG_03**

> ECHO-3: Something passed right by me. I didn't see it. I felt it.
> ECHO-3: The signal got louder when it did.

**터미널 로그 2 (구역 4) — ECHO_LOG_04**

> ECHO-1: ECHO-4 is gone. Card is here. She isn't.
> ECHO-1: Warden won't let us turn back.

## 7. 데이터 작업 목록

1. 레이아웃 복사 → B1용 새 번호(ID 규칙은 A1 작업 때 정해요).
2. R1B1 목표 복사 → ID 카드 개수와 배치 구역 수정.
3. 구역별 적, 문, 알람, 조명, 시체, 터미널 로그 설정.
4. RundownDataBlock의 TierB에 B1 추가.

## 8. 테스트 체크리스트

- [ ] ID 카드 4개가 구역마다 하나씩 나온다.
- [ ] 쉐도우가 처음 나오는 구역 2가 충분히 어둡다.
- [ ] 쉐도우 스카우트에 들켰을 때 웨이브가 감당할 만하다.
- [ ] 터미널 로그 두 개가 깨지지 않는다.
