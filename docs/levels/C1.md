# C1 레벨 기획서 (초안)

**[검토]** 표시는 연우님이 정해 줘야 하는 부분, **[확인 필요]**는 연우님 PC의 원작 덤프나 게임 테스트로 확인할 부분이에요.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 이름 | **[검토]** 제안: "Source" |
| 이야기 | 신호의 출처가 거대한 시설 장비라는 걸 알아낸다. |
| 주 목표 | **[검토]** 제안: 터미널 데이터 모으기(유형 12). 여러 터미널에서 장비 기록을 내려받아요. 다른 후보는 특수 터미널 명령(유형 5)이에요. |
| 보조 / 추가 목표 | 없음 |
| 콤플렉스 | 연구 시설 |
| 처음 나오는 적 | 빅 슈터(18), 하이브리드(33), Shooter_Spread(52), 스내처(46) |
| 플레이 느낌 | 터미널 조사. 에러 알람이 처음 나와서, 쉬지 못하고 계속 압박받아요. |

데이터 모으기를 추천하는 이유: 여러 터미널을 돌며 기록을 하나씩 모으는 흐름이 "조사"라는 이야기에 맞고, 내려받는 동안 버티는 긴장도 생겨요.

## 2. 목표 설정

- 터미널 수: 3개. 각 터미널에서 명령어로 데이터를 내려받아요. **[검토]**
- 원작 R5A3 목표를 복사해서 시작해요. **[확인 필요]** R5A3 목표 블록 번호.
- 내려받은 데이터가 터미널 화면에 나오면, 그 문구로 이야기를 전해요(장비 이름, 가동 기록).

## 3. 구역 구성

| 구역 | 역할 | 들어가는 문 | 적 | 이야기 장치 |
| --- | --- | --- | --- | --- |
| 0 | 착륙 지점 | (엘리베이터) | 없음 | Warden 브리핑 |
| 1 | 연구실 | Class II 알람(12) | 잠든 슈터, 빅 슈터 1 | 데이터 터미널 1 |
| 2 | 에러 알람 구역 | ://ERROR! 알람(67) | 트리클 웨이브 | 에러를 끄는 터미널은 구역 3에 |
| 3 | 메인프레임실 | Class III 알람(13) | 하이브리드 1, Shooter_Spread | 데이터 터미널 2, 에러 끄는 터미널 |
| 4 | 가장 깊은 연구실 | Class IV 알람(3) | 스내처 1, 잠든 적 Medium | 데이터 터미널 3, 터미널 로그 |

- 에러 알람: 스캔을 끝내도 웨이브가 안 멈추고, 다른 구역 터미널로 꺼야 해요. 구역에 TurnOffAlarmOnTerminal을 켜서 구역 3 터미널로 끄게 해요.
- 메인프레임실: 연구 시설의 tech_data_center_MainframeRoom_01 타일이 후보예요. **[확인 필요]**
- 스내처는 플레이어를 붙잡아서 동료가 구해줘야 해요. 4인 협동을 강조하는 적이에요.

## 6. 이야기 문구 (영어, 초안)

**Warden 브리핑**

> Retrieve operational records from three terminals. Identify the device. Do not attempt to disable it.

**레벨 설명**

> The signal has a source. It was built. Someone in this complex built it, and someone kept it running.

**데이터 터미널 화면 (내려받기 완료 시)**

> RECORD 1: Device designation [REDACTED]. Purpose: resonance amplification.
> RECORD 2: Power draw exceeds local grid. Reactor link required for full activation.
> RECORD 3: Subject response to signal: positive. Dormant specimen shows movement.

**터미널 로그 (구역 4) — ECHO_LOG_07**

> ECHO-1: The machine isn't sending a signal. It's calling something.
> ECHO-1: Warden told us to keep going. I'm starting to think Warden knew.
