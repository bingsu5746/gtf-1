# B2 레벨 기획서 (초안)

**[검토]** 표시는 연우님이 정해 줘야 하는 부분, **[확인 필요]**는 연우님 PC의 원작 덤프나 게임 테스트로 확인할 부분이에요.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 이름 | **[검토]** 제안: "Uplink" |
| 이야기 | 신호를 추적하려고 업링크를 연다. 신호가 연구 시설 쪽에서 온다는 걸 알게 된다. |
| 주 목표 | 터미널 업링크 (유형 8) |
| 보조 / 추가 목표 | 없음 |
| 콤플렉스 | 연구 시설 (Tech, 기본 ID 3)로 넘어가요. |
| 처음 나오는 적 | 차저(30), 차저 스카우트(41), 빅 차저(39), 줌어 스카우트(54) |
| 플레이 느낌 | 소리를 내면 대가가 큼. 업링크 중에는 버티면서 코드를 입력해요. |

## 2. 목표 설정

- 업링크 터미널 수: 1개. 확인 횟수: 원작 범위(1~12)에서 **5회**로 시작해요. **[검토]**
- 원작 R2B3 목표를 복사해서 시작해요. **[확인 필요]** R2B3 목표 블록 번호.
- 업링크 중 웨이브: 차저 위주. 원작 웨이브 개체군 Bullrush(5)가 후보예요.

## 3. 구역 구성

| 구역 | 역할 | 들어가는 문 | 적 | 이야기 장치 |
| --- | --- | --- | --- | --- |
| 0 | 착륙 지점 | (엘리베이터) | 없음 | Warden 브리핑 |
| 1 | 연구 시설 입구 | 스캔만 | 잠든 스트라이커, 쉐도우 | |
| 2 | 완전한 어둠 구역 | Class II 알람(12) | 잠든 차저 처음 등장, 차저 스카우트 1 | 터미널 로그 1 |
| 3 | 서버실 | Class III 알람(13) | 줌어 스카우트 1, 빅 차저 1 | ECHO 시체 |
| 4 | 업링크 구역 | Class IV 알람(3) | 잠든 적 Medium | 업링크 터미널, 터미널 로그 2 |

- 차저는 약점 배율이 없어서 머리를 노려도 소용이 없어요. 들키면 크게 손해 보는 적이에요.
- 업링크 구역은 넓은 방이 좋아요. 연구 시설의 허브 방(tech_lab_hub)이 후보예요. **[확인 필요]**

## 4. 난이도와 자원

- 자원 배율: 0.7
- 시작 상태: 100%

## 5. 분위기

- 조명: 구역 2는 완전한 어둠(Pitch_black_1). 손전등과 야광봉만 믿어야 해요.
- 업링크를 시작하면(목표 활성화 이벤트) 조명이 깜빡이게 해요. 후보: Monochrome_Blue_Flickering.

## 6. 이야기 문구 (영어, 초안)

**Warden 브리핑**

> Establish uplink. Triangulate signal origin. ECHO reached this terminal. Their upload did not complete.

**레벨 설명**

> The signal is not coming from the mines. It is coming from the research wing. Find out where.

**터미널 로그 1 (구역 2) — ECHO_LOG_05**

> ECHO-2: Lights went out on their own. Not a power failure. Something wanted it dark.

**터미널 로그 2 (구역 4) — ECHO_LOG_06**

> ECHO-1: Uplink shows the source. It's not a beacon. It's a machine. A big one.
> ECHO-1: Warden already had the coordinates. Why send us to find them?

**업링크 완료 후 Warden 메시지**

> Signal origin confirmed. Proceed.
