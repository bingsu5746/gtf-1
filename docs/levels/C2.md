# C2 레벨 기획서 (초안)

**[검토]** 표시는 연우님이 정해 줘야 하는 부분, **[확인 필요]**는 연우님 PC의 원작 덤프나 게임 테스트로 확인할 부분이에요.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 이름 | **[검토]** 제안: "Grid" |
| 이야기 | Warden이 신호를 끄려면 전력이 필요하다고 지시한다. 전력을 끌어오는 준비 임무. |
| 주 목표 | 전력 셀 배치 (유형 7) |
| 보조 / 추가 목표 | 없음 |
| 콤플렉스 | 연구 시설 |
| 처음 나오는 적 | 플라이어(42), 빅 플라이어(45), Striker_Berserk(53) |
| 플레이 느낌 | 셀을 들고 다니는 동안 무기를 못 써요. 팀이 셀 든 사람을 지켜야 해요. 웨이브 강도가 올라가요. |

## 2. 목표 설정

- 셀 개수: 원작 범위(3~4)에서 **3개**. 흩어진 발전기 3곳에 하나씩 꽂아요. **[검토]**
- 원작 R2B2 목표를 복사해서 시작해요. **[확인 필요]** R2B2 목표 블록 번호.
- C3(중앙 발전기)와 느낌을 다르게: C2는 "맵을 돌아다니며 나눠 꽂기", C3는 "한 곳에서 버티며 꽂기"예요.

## 3. 구역 구성

| 구역 | 역할 | 들어가는 문 | 적 | 이야기 장치 |
| --- | --- | --- | --- | --- |
| 0 | 착륙 지점 | (엘리베이터) | 없음 | Warden 브리핑 |
| 1 | 셀 보관 구역 | Class II 알람(12) | 잠든 적 Medium | 셀 3개 |
| 2 | 발전기 A | Class III 알람(13) | 강화 스트라이커(Berserk) 처음 등장 | 발전기 1 |
| 3 | 발전기 B, 높은 천장 | Class IV 알람(3) | 플라이어 처음 등장 | 발전기 2 |
| 4 | 발전기 C | Class V 알람(32) | 빅 플라이어 1, 잠든 적 Hard | 발전기 3, 터미널 로그 |

- 플라이어는 날아다니며 투사체를 쏴요. 천장이 높은 구역(AltitudeData)에 두면 어울려요.
- 빅 플라이어는 몸이 거의 무적이라 약점만 노려야 해요. 탄약을 많이 써요.
- 셀을 꽂을 때마다 이벤트로 조명이나 소리를 바꿔서, 전력이 들어갈수록 무언가 반응하는 느낌을 줘요.

## 4. 난이도와 자원

- 자원 배율: 0.65
- 시작 상태: 100%

## 5. 분위기

- 조명: 발전기를 꽂기 전에는 어둡고, 꽂으면 그 구역에 불이 들어와요.
- 안개: C1과 비슷하게.

## 6. 이야기 문구 (영어, 초안)

**Warden 브리핑**

> Restore power to three generators. Power is required to shut down the signal device.

**레벨 설명**

> Warden says the device can be stopped. It only needs power first.

**셀을 꽂을 때 Warden 메시지 (차례대로)**

> Generator one online.
> Generator two online. Signal output rising. This is expected.
> Generator three online. Proceed.

**터미널 로그 (구역 4) — ECHO_LOG_08**

> ECHO-2: We did this part too. Every generator we turned on, the signal got stronger.
> ECHO-2: Warden said that was expected.

## 7. 데이터 작업 목록

1. 레이아웃 복사 → C2용 새 번호.
2. R2B2 목표 복사 → 셀 개수, 발전기 위치 수정.
3. 셀을 꽂을 때 이벤트(조명, 소리, Warden 메시지) 설정.
4. RundownDataBlock의 TierC에 C2 추가.

## 8. 테스트 체크리스트

- [ ] 셀 3개와 발전기 3개가 정해진 구역에 나온다.
- [ ] 셀을 꽂을 때마다 이벤트가 나온다.
- [ ] 플라이어가 높은 구역에서 제대로 날아다닌다.
- [ ] C3와 너무 비슷하게 느껴지지 않는다.
