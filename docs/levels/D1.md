# D1 레벨 기획서 (초안)

**[검토]** 표시는 연우님이 정해 줘야 하는 부분, **[확인 필요]**는 연우님 PC의 원작 덤프나 게임 테스트로 확인할 부분이에요.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 이름 | **[검토]** 제안: "Amplify" |
| 이야기 | 리액터를 켠다. 신호는 꺼지기는커녕 더 강해진다. 플레이어는 자기 손으로 무언가를 깨운다. |
| 주 목표 | 리액터 가동 (유형 1) |
| 보조 / 추가 목표 | 없음 |
| 콤플렉스 | **[검토]** 제안: 연구 시설(lab_reactor_HA_01 또는 _02). B2부터 연구 시설에 있었으니 이어지는 게 자연스러워요. 다른 후보는 채굴 시설(mining_reactor_*)이에요. |
| 처음 나오는 적 | 탱크(29), 나이트메어 스카우트(56), 나이트메어 빅 스트라이커(62), 나이트메어 베이비(63) |
| 플레이 느낌 | 리액터 웨이브 방어. 웨이브마다 코드를 찾으러 다른 구역까지 뛰어가야 해요. |

## 2. 목표 설정 (리액터 웨이브)

원작 R1C1(8웨이브)을 출발점으로 해서 **10웨이브**로 늘려요. 원작 R2D2도 10웨이브예요. **[검토]**
코드는 다른 구역 터미널에 있어요(VerifyInOtherZone). 시간 단위는 초예요. 숫자는 테스트로 조절해요.

| 웨이브 | 대기 | 전투 | 코드 입력 제한 | 적 | 연출 |
| --- | --- | --- | --- | --- | --- |
| 1 | 20 | 60 | 45 | 리액터 기본(6) | 리액터 가동음 |
| 2 | 30 | 60 | 45 | 리액터 기본 | |
| 3 | 40 | 60 | 45 | 기본 + 대형 | 조명 깜빡임 시작 |
| 4 | 50 | 60 | 45 | 기본 + 대형 | 안개 조금 짙어짐 |
| 5 | 60 | 60 | 45 | 나이트메어 스카우트 처음 등장 | Warden 메시지 1 |
| 6 | 80 | 70 | 45 | 기본 + 나이트메어 빅 스트라이커 | |
| 7 | 100 | 90 | 45 | 나이트메어 베이비 (CursedChildren, 71) | 안개 더 짙어짐 |
| 8 | 110 | 90 | 45 | 탱크 1 (Tank, 16) | Warden 메시지 2 |
| 9 | 110 | 90 | 45 | 기본 + 대형 2 | 빨간 조명 |
| 10 | 120 | 90 | 45 | 마더 (Baseline Reactor S-Child, 44) | 낮은 신호음, 리액터 완료 |

- 1~8웨이브의 대기, 전투, 코드 입력 제한 시간은 원작 R1C1과 같아요. 9~10웨이브는 그 수치를 바탕으로 늘린 제안 값이에요. 웨이브별 적 구성은 원작과 다르게 우리 이야기에 맞춰 바꿨어요.
- "리액터가 돌수록 무언가 깨어난다": 웨이브마다 이벤트로 소리, 안개, 조명을 바꿔요.
- 나이트메어 계열은 "리액터가 신호를 키워서 적이 변이한다"는 이야기로 보여 줘요.
- 리액터 조명 설정: LightsOnFromBeginning을 끄고 LightsOnWhenStartupComplete를 켜면, 리액터가 다 돌았을 때 불이 들어와요. 이 순간을 "깨어남"으로 써요.

## 3. 구역 구성

| 구역 | 역할 | 들어가는 문 | 적 | 이야기 장치 |
| --- | --- | --- | --- | --- |
| 0 | 착륙 지점 | (엘리베이터) | 없음 | Warden 브리핑 |
| 1 | 리액터 가는 길 | Class III 알람(13) | 잠든 적 Hard | |
| 2 | 코드 터미널 구역 A | Class IV 알람(3) | 잠든 적 Medium | 코드 터미널 |
| 3 | 코드 터미널 구역 B | Class IV 알람(81, 하이브리드 포함) | 잠든 적 Medium | 코드 터미널, ECHO 시체 |
| 4 | 리액터 방 | Class V 알람(32) | 리액터 웨이브 | 리액터, 터미널 로그 |

- 리액터 방과 코드 터미널 구역 사이 거리가 난이도를 정해요. 너무 멀면 4인이라도 코드 입력 시간이 모자라요.

## 4. 난이도와 자원

- 자원 배율: 0.6
- 시작 상태: 100%
- 리액터 방에 탄약 보급 상자를 넉넉히 둬요. 10웨이브를 버텨야 해요.

## 5. 분위기

- 시작: 어두운 리액터 방.
- 진행: 웨이브가 지날수록 깜빡이는 조명 → 빨간 조명 → 짙은 안개.
- 끝: 리액터 완료와 함께 불이 들어오고, 낮은 신호음이 울려요.

## 6. 이야기 문구 (영어, 초안)

**Warden 브리핑**

> Start the reactor. Reactor output will be redirected to shut down the signal device.

**레벨 설명**

> ECHO's last message said not to start it. Warden says it is the only way to make the signal stop.

**Warden 메시지 1 (5웨이브)**

> Signal output increasing. This is expected. Continue.

**Warden 메시지 2 (8웨이브)**

> Redirect complete. Continue startup.

**리액터 완료 시 Warden 메시지**

> Startup complete. Signal at full strength. Thank you.

**터미널 로그 (구역 4) — ECHO_LOG_10**

> ECHO-1: I didn't start it. I couldn't. Warden stopped answering.
> ECHO-1: Something under the reactor is breathing.

## 7. 데이터 작업 목록

1. 리액터 방이 있는 레이아웃 복사 → D1용 새 번호.
2. 원작 R1C1 또는 R2D2 리액터 목표 복사 → 10웨이브, 웨이브별 적과 이벤트 수정.
3. 코드 터미널을 다른 구역에(VerifyInOtherZone).
4. 리액터 조명 설정(LightsOnWhenStartupComplete).
5. RundownDataBlock의 TierD에 D1 추가.
