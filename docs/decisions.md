# SIGNAL 룬다운 결정 기록

지금까지 정한 내용이에요. 새로 정한 게 생기면 여기에 덧붙여요.

## 기본 방향

- **게임:** GTFO 커스텀 룬다운. MTFO 4.6.3, 게임 버전(revision) 34873.
- **인원과 난이도:** 4인 기준 하드코어. 1~2인은 봇과 함께 플레이해요. 처음에는 1~2인 봇 없이를 생각했지만, 인원을 막을 수 없어서 4인 기준으로 바꿨어요.
- **이야기 방향:** 원작 세계관 안의 외전. 고립된 공포(에이리언, 더 씽 계열).
- **규모:** 정규 룬다운. 스토리를 먼저 정하고 레벨을 하나씩 만들어요.
- **표시 방식:** 원작 룬다운 옆에 SIGNAL을 같이 띄워요(GameSetup에 원작 ID + 100).

## 줄거리: 신호 (The Signal)

> 콤플렉스 깊은 곳에서 정체 모를 신호가 계속 나온다. 신호를 조사하러 보낸 앞선 팀들은 모두 연락이 끊겼다. Warden은 다시 4인 팀을 깨워 같은 경로로 보낸다.
> 신호에 가까워질수록 슬리퍼들은 이상하게 행동한다.
> D 티어에서 Warden은 "신호를 끄기 위해" 리액터를 가동하라고 지시하지만, 리액터는 사실 신호를 증폭하는 장치에 전력을 넣는다. 플레이어는 자기 손으로 무언가를 깨운다.
> E 티어에서 깨어난 것이 괴물이라는 걸 알게 되고, 탈출한다. Warden은 처음부터 알고 있었다.

- **앞선 팀 이름:** ECHO (2026-10-24). 터미널 로그에서는 ECHO-1, ECHO-2처럼 팀원을 번호로 불러요.

## 레벨 구성 (8개)

| 레벨 | 이야기 | 플레이 |
| --- | --- | --- |
| A1 | 신호를 처음 추적. 연락이 끊긴 앞선 팀의 첫 흔적. | 기본 잠입과 탐색 |
| B1, B2 | 신호에 가까워질수록 슬리퍼가 이상해짐. 앞선 팀의 무전 로그가 불안해짐. | 은신 중심, 소리를 내면 대가가 큼 |
| C1 | 신호의 출처가 거대한 시설 장비라는 걸 알아냄. | 터미널 조사 |
| C2 | Warden이 신호를 끄려면 전력이 필요하다고 지시. 전력을 끌어오는 준비 임무. | 준비 임무, 웨이브 강도 상승 |
| C3 | 앞선 팀의 마지막 기록 발견. 그들도 리액터 앞까지 갔다가 연락이 끊김. | D 직전의 불길한 예감 |
| D1 | 리액터 가동. 신호가 꺼지기는커녕 더 강해짐. | 리액터 가동 웨이브 방어 |
| E1 | 깨어난 것이 괴물. Warden은 알고 있었음. | 탈출, 멈추면 끝 |

## 꼭 넣을 목표 (2026-10-24)

리액터 가동, HSU 샘플 채취, ID 카드 모으기, 전력 셀 배치, 터미널 업링크, 생존. C3는 중앙 발전기 클러스터로 정했어요.

E1의 깨어난 괴물은 불사 탱크(Tank_Boss, ID 47)로 정했어요. 마더나 메가 마더도 어딘가에 넣고 싶어요. 메가 마더는 E1이 아닌 다른 레벨에 넣어요(어느 레벨인지는 검토 중).

게임에 나오는 몬스터를 룬다운 전체에 최대한 다 넣어요. 단, 크라켄은 넣지 않아요. 레벨별 배치 제안은 `docs/spec.md` 4-1장에 있어요(검토 대기). 레벨별 배치 제안은 `docs/spec.md` 4장에 있어요(검토 대기).
