# SIGNAL 룬다운 기획서 (초안)

`docs/decisions.md`에서 정한 줄거리와 레벨 구성을, 게임 데이터로 어떻게 만들지 정리한 문서예요.
숫자와 ID는 데이터 레퍼런스 보고서(게임 버전 34873 덤프 기준)에서 가져왔어요.
**[검토]** 표시는 연우님이 정해 줘야 하는 부분이에요.

## 1. 한 줄 요약

> 연락이 끊긴 앞선 팀의 흔적을 따라 신호를 쫓다가, 신호를 끄라는 Warden의 지시대로 리액터를 켜고, 그 손으로 깨운 괴물에게서 도망친다.

## 2. 긴장 곡선

| 구간 | 레벨 | 플레이어가 느낄 것 | 플레이 중심 |
| --- | --- | --- | --- |
| 도입 | A1 | "뭔가 이상하다" | 잠입, 탐색, 로그 읽기 |
| 고조 | B1, B2 | "소리를 내면 끝이다" | 은신. 스카우트와 쉐도우 |
| 의심 | C1~C3 | "이 지시, 맞는 건가?" | 터미널 조사, 준비 임무, 웨이브 강도 상승 |
| 폭발 | D1 | "우리가 깨웠다" | 리액터 웨이브 방어 |
| 도주 | E1 | "멈추면 죽는다" | 추격당하며 탈출 |

## 3. 룬다운 공통 규칙

### 인원과 난이도
- 4인 기준 하드코어. 1~2인은 봇과 함께 플레이 (decisions.md 기준).
- 하드코어는 적 수보다 **자원 부족과 실수의 대가**로 만들어요.
  - 구역 자원 배율(HealthMulti, WeaponAmmoMulti, ToolAmmoMulti): 0.5~0.75. 원작 어려운 레벨이 0.75를 써요.
  - 알람: Class 숫자를 올리기보다 Surge, 에러 알람을 섞어요.
  - 적: 스카우트와 차저를 늘려서 은신 실수의 대가를 키워요.
  - 시작 상태: SpecialOverrideData로 체력이나 탄약이 모자란 채 시작할 수 있어요. 쓸지는 레벨마다 정해요.

### 레벨 사이 이어지는 장치
- **앞선 팀의 흔적:** 시체(CorpsesInZone)와 터미널 로그(TerminalPlacements.LocalLogFiles)로 보여 줘요. 레벨이 진행될수록 로그가 점점 불안해지고, C3에서 마지막 기록이 나와요.
- **신호가 강해지는 연출:** 티어가 올라갈수록 안개가 짙어지고(A: 엷은 안개 → E: 감염 안개), 조명이 어두워지고, 적이 다시 생기는(EnemyRespawning) 구역이 생겨요.
- **Warden 메시지:** 처음에는 평범한 지시처럼, C 티어부터 조금씩 앞뒤가 안 맞게 써요. E1에서 "처음부터 알고 있었다"가 드러나요.

### 텍스트
- 게임 안 문구(레벨 이름, 목표 설명, 로그, Warden 메시지)는 영어로 써요.
- **[확인 필요]** 레퍼런스 보고서에는 "터미널 로그와 메시지는 텍스트 표(TextDataBlock)의 ID를 가리킨다"고 되어 있고, CLAUDE.md에는 "문자열을 직접 넣어도 된다"고 되어 있어요. A1에서 로그 하나를 넣어 게임에서 확인한 뒤 방식을 정해요.

### ID 규칙
- 룬다운 ID: 100.
- 새로 만드는 블록(레이아웃, 목표, 웨이브 등)도 원작과 겹치지 않는 번호를 써요. **[검토]** 블록마다 "100번대부터" 같은 규칙을 A1 작업 때 정해서 decisions.md에 적어요.

## 4. 레벨별 설계

각 레벨의 "목표 후보"는 원작 데이터에 있는 Warden 목표 유형이에요(괄호 안 숫자가 유형 번호).

### 꼭 넣을 목표 (2026-10-24 연우님 결정)

리액터 가동(1), HSU 샘플 채취(0), ID 카드 모으기(3), 전력 셀 배치(7), 터미널 업링크(8), 생존(11).
레벨 배치 제안은 아래와 같아요. **[검토]**

| 레벨 | 주 목표 | 이유 |
| --- | --- | --- |
| A1 | HSU 샘플 채취(0) | 지금 A1이 원작 R1A1(HSU 샘플) 복사본이라 그대로 살릴 수 있어요. 앞선 팀이 하다 만 채취를 이어서 해요. |
| B1 | ID 카드 모으기(3) | 연락이 끊긴 앞선 팀원들의 ID 카드를 모아요. 원작 R1B1도 ID 카드 12개예요. |
| B2 | 터미널 업링크(8) | 신호를 추적하려고 업링크를 열어요. |
| C1 | 터미널 데이터 모으기(12) 또는 특수 터미널 명령(5) | 신호의 출처를 조사해요. |
| C2 | 전력 셀 배치(7) | "신호를 끄려면 전력이 필요하다"는 지시에 맞는 준비 임무예요. |
| C3 | 중앙 발전기 클러스터(9) | 리액터로 가는 마지막 전력 준비예요. 셀을 꽂을 때마다 안개가 바뀌어서 불길한 예감을 키우기 좋아요. (2026-10-24 연우님 결정) |
| D1 | 리액터 가동(1) | 줄거리의 핵심 장면이에요. |
| E1 | 생존(11) | 멈추면 끝나는 탈출전이에요. |

한 레벨에 보조 목표(벌크헤드 너머)를 더 둘 수 있으니, 다른 목표를 보조 목표로 한 번 더 쓰는 것도 가능해요.

### A1 "First Trace" — 첫 흔적
- **이야기:** 신호를 처음 추적. 연락이 끊긴 앞선 팀의 첫 흔적을 찾는다.
- **목표 후보:** HSU 샘플 채취(0). 위 배치 표 참고.
- **콤플렉스:** 채굴 시설(Mining).
- **분위기:** 엷은 안개, 터미널 로그 1~2개, 앞선 팀 시체.
- **적:** 잠든 적 Easy~Medium, 스카우트 소수.
- **하드코어 포인트:** 실수해도 회복할 여유는 주되, 자원은 원작 A보다 적게.
- **지금 상태:** 원작 R1A1을 복사해 이름만 바꾼 상태예요. 다음 작업에서 위 내용으로 바꿔요.

### B1 — 이상한 슬리퍼
- **이야기:** 신호에 가까워질수록 슬리퍼가 이상해진다. 앞선 팀 무전 로그가 불안해진다.
- **목표 후보:** ID 카드 모으기(3) — 앞선 팀원들의 ID 카드를 모으는 설정.
- **콤플렉스:** 채굴 시설.
- **분위기:** 어두운 조명(DarkGrey, DarkBlue 계열).
- **적:** 스카우트 비중 증가. 쉐도우가 처음 나와요.

### B2 — 소리의 대가
- **이야기:** B1과 같은 흐름. 신호의 방향이 연구 시설 쪽이라는 걸 알게 된다.
- **목표 후보:** 터미널 업링크(8).
- **콤플렉스:** 연구 시설(Tech)로 넘어가요.
- **분위기:** 완전한 어둠 구역(Pitch_black) 일부.
- **적:** 쉐도우 스카우트, 차저 스카우트. 들키면 크게 손해 보는 배치.

### C1 — 신호의 출처
- **이야기:** 신호의 출처가 거대한 시설 장비라는 걸 알아낸다.
- **목표 후보:** 터미널 데이터 모으기(12) 또는 특수 터미널 명령(5).
- **콤플렉스:** 연구 시설. 메인프레임실(tech_data_center_MainframeRoom_01)이 어울려요.
- **적:** 에러 알람을 처음 넣어요(끄는 터미널은 다른 구역에).

### C2 — 전력 준비
- **이야기:** Warden이 신호를 끄려면 전력이 필요하다고 지시한다.
- **목표 후보:** 전력 셀 배치(7). 셀 3~4개를 여러 발전기에 나눠 꽂아요.
- **콤플렉스:** 연구 시설.
- **분위기:** 셀을 하나 꽂을 때마다 이벤트로 조명이나 소리를 바꿔서, 전력이 들어갈수록 무언가 반응하는 느낌을 줘요.
- **적:** 웨이브 강도 상승. 하이브리드 등장.

### C3 — 마지막 기록
- **이야기:** 앞선 팀의 마지막 기록. 그들도 리액터 앞까지 갔다가 연락이 끊겼다.
- **목표:** 중앙 발전기 클러스터(9). 한 곳에 모인 발전기에 셀을 모두 꽂아요.
- **분위기:** D1 직전의 불길한 예감. 셀을 꽂을 때마다 안개가 단계별로 짙어지게 해요. 리액터로 가는 길의 입구까지만 보여 줘요.
- **앞선 팀의 마지막 기록:** 발전기 근처 터미널 로그로 넣어요.
- **C2와 겹치는 점:** C2(전력 셀 배치)도 셀을 꽂는 목표예요. C2는 "흩어진 발전기에 나눠 꽂기", C3는 "한 곳에 모아 꽂으며 안개 변화"로 느낌을 다르게 만들어요. 테스트해서 너무 비슷하면 C2를 바꿔요.

### D1 — 리액터 가동
- **이야기:** 리액터를 켠다. 신호는 꺼지기는커녕 더 강해진다.
- **목표:** 리액터 가동(1). 코드는 다른 구역 터미널에서 찾게(VerifyInOtherZone) 해서 팀이 뛰어다니게 해요.
- **콤플렉스:** 리액터 방이 있는 채굴(mining_reactor_*) 또는 연구(lab_reactor_*). **[검토]**
- **웨이브:** 원작 R1C1은 8웨이브, R2D2는 10웨이브예요. 우리는 8~10웨이브에서 시작해 테스트로 조절해요.
- **연출:** 웨이브마다 이벤트로 소리, 안개, 깜빡이는 조명을 넣어서 "리액터가 돌수록 무언가 깨어난다"를 보여 줘요. 마지막 웨이브에 마더.
- **적:** 리액터 웨이브 개체군(Baseline Reactor, ID 6 / S-Child, ID 44).

### E1 — 탈출
- **이야기:** 깨어난 것은 괴물이었다. Warden은 처음부터 알고 있었다.
- **목표 후보:** 생존(11). 착륙하자마자 에러 웨이브, 엘리베이터 쪽에서 오는 적(From Elevator 웨이브).
- **콤플렉스:** 채굴 시설(동굴).
- **분위기:** 감염 안개, 빨간 단색 조명. 괴물의 정체를 차원 플래시로 짧게 보여 주는 것도 가능해요.
- **괴물:** 불사 탱크(Tank_Boss, ID 47). 죽일 수 없는 추격자예요. (2026-10-24 연우님 결정)

### 마더 넣을 자리 (제안) **[검토]**
연우님이 마더나 메가 마더도 넣고 싶어 해요. 데이터에 있는 마더 계열은 마더(36, HP 1,000), P-마더(37, HP 2,500), 메가 마더(55, HP 5,000)예요.
- **C 티어 잠든 마더:** 은신 전용(Pure Sneak) 배치로 잠든 마더를 둬요. 깨우면 큰일 나는 장애물이에요.
- **D1 마지막 웨이브:** 원래 계획대로 리액터 마지막 웨이브에 마더를 넣어요. 리액터 개체군 S-Child(44)의 미니보스 자리가 마더예요.
- **메가 마더:** E1에는 넣지 않아요(2026-10-24 연우님 결정). 다른 레벨에 넣어요. 제안은 C3예요. 셀을 다 꽂은 뒤 메가 마더가 나와서, D1 직전의 큰 고비가 돼요. **[검토]**
- **[확인 필요]** 메가 마더를 웨이브로 부를지, 잠든 상태로 둘지에 따라 필요한 데이터가 달라요. 원작 데이터에 메가 마더가 들어간 웨이브 개체군이나 적 그룹이 있는지는 아직 확인하지 못했어요. 연우님 PC의 원작 덤프에서 확인해야 해요.

## 5. 만드는 순서

1. A1을 실제 레벨로 만들어요. 이때 레이아웃, 목표, 터미널 로그, ID 규칙을 한 번씩 다 해 봐요.
2. 연우님 PC에서 테스트 → 고칠 점을 decisions.md에 적어요.
3. B1부터 한 레벨씩 같은 방식으로 진행해요.
4. 8개가 다 들어가면 전체를 이어서 플레이하며 난이도를 맞춰요.

## 6. 연우님이 검토해 줄 것

2. 목표 배치 표(4장 첫 부분)가 괜찮나요?
3. D1 리액터 방: 채굴과 연구 중 어느 쪽이 좋나요?
4. 마더 넣을 자리(4장 E1 아래): 어느 안을 쓸까요?
